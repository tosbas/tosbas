# Salut ! 👋 Moi, c'est Tosbas (Thomas)

💻 Développeur web autodidacte, passionné par le développement et la création d'applications.

Après plusieurs expériences dans le développement web, notamment deux années en CDI en tant que développeur web, je poursuis aujourd'hui mon parcours avec une formation de **Concepteur Développeur d'Applications**, avec un intérêt particulier pour JavaScript, React, Node.js et l'écosystème DevOps.

J'aime comprendre ce qui se passe derrière le code, apprendre de nouvelles technologies et concevoir des projets concrets.
